段階6：プログラムを直して提出する

これが今日の最後の段階です。プログラムを実行し、わざと混ぜてある不具合を見つけて直し、 提出するところまで進めます。

1. 最初のプログラムを実行する

  1. Codespaces の下側にある Terminal（黒い画面）をクリックする。 見当たらない場合は、上のメニューの Terminal → New Terminal を押す。
  2. 次を入力して Enter を押す。 
    python checkpoints/01/hello.py
  3. 次のように表示されれば成功です。 
    Hello, pp2026!

2. 不具合を見つける

checkpoints/01/leap.py は、西暦を渡すと、その年が閏年（うるう年）かどうかを答える プログラムです。これが正しく答えられるかを、確認用のプログラムで調べます。

python checkpoints/01/check_leap.py

次のように表示されます。

  年     正しい答え   あなたのプログラム   判定
  ------ ------------ -------------------- ----
  2024   閏年         閏年                 ✓ OK
  2025   閏年でない   閏年でない           ✓ OK
  2000   閏年         閏年                 ✓ OK
  1900   閏年でない   閏年                 ✗ NG
  2100   閏年でない   閏年                 ✗ NG
  2400   閏年         閏年                 ✓ OK

6 件中 2 件が NG です。
NG の年が守れていない決まり：
  1900 年 → 決まり②：100 で割り切れる年は閏年でない
  2100 年 → 決まり②：100 で割り切れる年は閏年でない

赤い ✗ NG の行が、プログラムが間違えた年です。1900 年と 2100 年は、本当は 閏年でないのに、プログラムは「閏年」と答えています。

3. 閏年の決まりを確かめる

「4 で割り切れれば閏年」と思っていた人も多いはずです。実は、配ったプログラムもそう書かれています。 でも、本当の決まりはもう少しだけ複雑です。

そもそも、なぜ閏年があるのか

地球が太陽のまわりを 1 周するのには、約 365.2422 日かかります。カレンダーの 1 年は 365 日なので、そのままだと毎年 0.24 日ずつ季節とずれていきます。そこで、ときどき 2 月 29 日を足して 調整します。足し方を細かくしていくと、本物の 1 年に近づきます。

足し方の決まり1 年の平均の長さ本物（365.2422 日）とのずれ
足さない365.0000 日4 年で約 1 日ずれる
① 4 で割り切れる年に足す365.2500 日足しすぎ。約 130 年で 1 日ずれる
② ただし 100 で割り切れる年は足さない365.2400 日今度は少し足りない
③ ただし 400 で割り切れる年は足す365.2425 日ほぼぴったり。約 3000 年で 1 日

「4 で割り切れれば閏年」は①までの考え方です。それだと足しすぎになるので、②と③があります。 2000 年が閏年だったのは③のおかげで、1900 年が閏年でなかったのは②のためです。

まとめると、閏年かどうかは、次の順に 3 つの問いを立てると決まります。

① 4 で割り切れる？
いいえ → 閏年でない
はい ↓
今のプログラムは、ここから下を見ていません
② 100 で割り切れる？
いいえ → 閏年
はい ↓
③ 400 で割り切れる？
はい → 閏年
いいえ → 閏年でない

確認に使っている 6 つの年を、この問いに当てはめると次のようになります。

年① 4 で
割り切れる		② 100 で
割り切れる		③ 400 で
割り切れる		正しい答え今のプログラム
2024○××閏年閏年
2025×××閏年でない閏年でない
2000○○○閏年閏年
1900○○×閏年でない閏年
2100○○×閏年でない閏年
2400○○○閏年閏年

今のプログラムは①しか見ていないので、①が○の年はすべて「閏年」と答えます。2000 年と 2400 年は 答えが合っていますが、たまたま合っているだけです。

4. 直す

左側のファイル一覧から checkpoints/01/leap.py を開いてください。直すのは、 赤で囲んだ 3 行目だけです。

1  def is_leap_year(year):
2      """西暦 year が閏年なら True、そうでなければ False を返す。"""
3      return year % 4 == 0          ← ①しか見ていない。②と③も見るように直す
4
5
6  if __name__ == "__main__":
7      for year in [2024, 2025, 2000, 1900]:
8          print(year, is_leap_year(year))
ヒント
  • year % 100 == 0 は「100 で割り切れる」、year % 100 != 0 は「100 で割り切れない」という意味です。
  • 1 行で書いても（and と or を使う）、if を使って何行かに分けてもかまいません。
  • 6 行目から下は触らなくてかまいません。

直したら保存し（Cmd+S または Ctrl+S）、もう一度確かめます。

python checkpoints/01/check_leap.py

5. commit と push で提出する

ターミナルで、次の4つを順番に入力します。

git status
git add -A
git commit -m "閏年の判定を直す"
git push
  • git status：変更したファイルの一覧を見る。checkpoints/01/leap.py が 「modified」と表示されるはずです。
  • git add -A：変更を、次の commit に含めるものとして登録する。
  • git commit -m "…"：登録した変更を、説明を付けて記録する。
  • git push：記録を GitHub の自分のリポジトリに送る。

初めて commit するとき、名前やメールアドレスの設定を求められることがあります。表示される 指示に従ってください。名前には本名ではなく GitHub のユーザー名を使ってください。

6. 確認（Actions）を見る

push すると、GitHub が自動で、あなたのリポジトリのプログラムを GitHub のコンピューターで動かして 確かめます。これを Actions と呼びます。確かめる内容は、ターミナルで実行した hello.py と check_leap.py と同じです。

  1. Vivaldi で自分のリポジトリ（github.com/<自分のユーザー名>/pp2026）を開く。
  2. 上のタブから Actions を選ぶ。
  3. 一番上の実行結果の印が、黄色の丸（実行中）から、緑の ✓（成功）に変わるのを確認する。 1 分ほどかかります。

赤い ✗ になったら、その行を押し、「第1回」→ 赤い印の付いた項目の順に開いてください。 ターミナルで見たのと同じ表が出ているので、どの年が NG かが分かります。直して、もう一度 5 の手順で push してください。

7. TACT で提出する（必ずこの形式で！）

自分のリポジトリの URL を TACT に提出します。提出された URL は、プログラムでまとめて読み取ります。 形式が違うと読み取れず、提出していないことになります。手で打たず、コピーして貼り付けてください。

  1. Vivaldi で自分のリポジトリ（pp2026）のトップページを開く。
  2. アドレス欄の URL をすべて選んでコピーする。
  3. TACT の課題「第1回：リポジトリの URL の提出」を開き、提出欄に貼り付けて提出する。
提出する形式（これ 1 行だけ）
https://github.com/symelon54/pp2026

symelon54 の部分が、自分の GitHub のユーザー名になります。

提出した内容判定
https://github.com/symelon54/pp2026✓ 正しい
symelon54（ユーザー名だけ）✗ URL にする
https://github.com/symelon54（/pp2026 がない）✗ リポジトリのページを開いてコピーする
https://github.com/symelon54/pp2026 です。よろしくお願いします。✗ URL のほかに何も書かない
https://github.com/symelon54/pp2026/tree/main/checkpoints✗ リポジトリのトップページの URL にする
https://github.com/symelon-dev/pp2026-template✗ テンプレートではなく、自分のリポジトリ

名前・学籍番号・あいさつは書きません（TACT がだれの提出かを記録しています）。

8. Codespaces を止める

無料枠を節約するため、使い終わったら Codespaces を止めます。 github.com/codespaces を開き、自分の Codespace の「…」メニューから Stop codespace を押してください。
