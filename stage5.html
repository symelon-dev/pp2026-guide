段階5：自分のリポジトリを作り、Codespaces を開く

ここから、学期を通して使う自分のリポジトリを作ります。回ごとの課題は、このリポジトリの中に 増えていきます。

1. テンプレートからリポジトリを作る

  1. Vivaldi で github.com/symelon-dev/pp2026-template を開く。
  2. 画面上部の緑のボタン Use this template を押し、 Create a new repository を選ぶ。
  3. Owner が自分のアカウントになっていることを確かめる。
  4. Repository name に pp2026 と入力する。
  5. 公開範囲を Private にする（Public のままにしない）。
  6. Create repository from template を押す。
リポジトリ名は必ず pp2026 にしてください（半角小文字）。公開範囲は必ず Private にしてください。

2. 教員を招待する

  1. 作られた自分のリポジトリ（<自分のユーザー名>/pp2026）を開く。
  2. Settings タブを押す。
  3. 左側の一覧から Collaborators を押す。
  4. Add people を押す。
  5. 検索欄に symelon-dev と入力し、表示された名前を選ぶ。
  6. Add symelon-dev to this repository を押す。

3. Codespaces を開く

  1. リポジトリのトップページで、緑の Code ボタンを押す。
  2. Codespaces のタブを選ぶ。
  3. Create codespace on main を押す。
  4. 1〜3分ほど待つ。画面が切り替わり、VS Code のような画面が開く。
初回は環境の準備に数分かかります。読み込み中の画面のまま待ってください。 うまく開かないときは 困ったときは を見てください。

できたことを確かめる

終わったものにチェックを入れましょう。

  • 自分の pp2026 が Private で作られている
  • 教員（symelon-dev）を Collaborator に招待した
  • Codespaces の画面の左側に、ファイルの一覧（README.md、checkpoints など）が見えている

グループ全員がここまで終わったら、代表の1人が教員に報告し、合言葉を受け取ってください。
