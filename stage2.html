段階2：GitHub アカウントを作る

GitHub は、プログラムを保存し、提出するために使うサービスです。段階1で作った Google アカウントを使って作ります。新しく別のパスワードを決める必要はありません。

1. GitHub アカウントを作る

  1. Vivaldi で github.com/signup を開く。
  2. Continue with Google のボタンを押す。
  3. 段階1で作った Google アカウントを選ぶ（複数表示される場合は、アドレスをよく見て選ぶ）。
  4. GitHub のユーザー名を聞かれたら、段階1で決めた文字列と同じものにする （例：symelon54）。
  5. 画面の指示に従って進める。
GitHub のユーザー名に、本名や学籍番号を含めないでください。

2. メールアドレスの確認

Google アカウントのメールに、GitHub からの確認メールが届くことがあります。届いていたら、 メールを開いて確認を済ませてください。確認が終わらないと、リポジトリを作れません。

3. できたことを確かめる

Vivaldi で github.com/settings/profile を開き、自分で決めたユーザー名が表示されていれば成功です。

早く終わった人へ（任意）

グループ全員が終わるまで時間が余ったら、2要素認証を設定してみましょう。

  1. github.com/settings/security を開く。
  2. 「Two-factor authentication」の「Enable two-factor authentication」を押す。
  3. Authenticator app を選ぶ（スマートフォンがなくても、PC 用の認証アプリで設定できる）。
  4. 表示される手順に従って設定する。
