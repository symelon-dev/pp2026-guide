困ったときは

まず、この順で解決を試す

  1. 画面のメッセージを読む。英語でも、知らない単語だけ調べれば意味が分かることが多いです。
  2. グループの仲間に画面を見せる。同じところでつまずいた人や、先に終わった人がいるはずです。 同じ手順を、仲間の画面と見比べてみてください。
  3. 生成AIに聞く。何をしようとして、何が起きたかを伝えます。たとえば次のように聞きます。 
    GitHub Codespaces のターミナルで git push をしたら、次のメッセージが出ました。
何が起きていて、どうすればよいですか。

（ここに画面のメッセージを貼り付ける）
    段階3より前でまだ登録していない人も、ChatGPT（chatgpt.com）はログインしなくても使えます。 仲間の画面の生成AIに聞いてもかまいません。
  4. それでも解決しなければ、後回しにして先に進む。あとの段階に関係しないもの （2要素認証、Gravatar など）は、とばしてかまいません。段階5・6は、自宅で続けることもできます （期限は10月12日（月）23:59）。
生成AIにメッセージを貼り付けるときは、パスワードや電話番号、本名が含まれていないかを確かめてから 送ってください。

生成AIの答えが正しいとは限りません。言われたとおりにやってみて、本当に解決したかを自分の目で 確かめてください。これも、この講義で身につけたい力の 1 つです。

Google アカウントの作成で、電話番号の確認が通らない

番号を半角で、先頭の 0 も含めて入力しているかを確かめてください。同じ番号で短い時間に何度も 試すと、しばらく通らなくなることがあります。数分おいてから試してください。表示されたメッセージを 生成AIに伝えて、ほかの確認の方法がないか聞くのも手です。

GitHub のユーザー名が、すでに他の人に使われている

段階1の果物の部分を別の果物に変えて、もう一度試してください。

Claude の電話番号の確認が通らない

その場で粘らずに、Claude の登録はとばして ChatGPT と Gemini で先に進んでください。 18 歳未満の人も、Claude はとばします。

Opera で拡張機能が入れられない（「Chrome に追加」が押せない）

Opera のアドオンサイト（addons.opera.com）で「Install Chrome Extensions」を検索して入れてから、 Chrome ウェブストアのページを開き直してください。ボタンが Opera に追加 に変わります。

まもるくんを入れたのに、架空の個人情報がそのまま送信された

使っているのが Claude なら、まもるくんは働きません（対応していません）。ChatGPT か Gemini で 試してください。それでも何も起きない場合は、拡張機能が有効になっているか（ブラウザの拡張機能の 一覧でオンになっているか）を確かめてください。見落としもありうる道具なので、何も起きなかったことも 1 つの結果として覚えておいてください。

画像生成AIで「上限に達しました」と出る

無料で作れる枚数には 1 日の上限があります。もう一方のサービス（ChatGPT と Gemini）に切り替えるか、 CHARAT（charat.me）で作ってください。

Gravatar の確認メールが届かない

講義用の Gmail を開いているか（私用のアドレスを見ていないか）、迷惑メールのフォルダに入って いないかを確かめてください。数分待っても届かなければ、Gravatar は後回しにして、GitHub への アバターの登録を先に済ませてください。

「Use this template」のあと、Owner が自分のアカウントになっていない

Owner の欄が symelon-dev（教員のアカウント）のままになっていないか 確かめてください。自分のユーザー名に変えてから作成してください。

Codespaces がなかなか開かない・固まる

教室の回線が混み合っている可能性があります。1〜2分待ってから、タブを再読み込みしてください。 それでも開かない場合は、段階5・6を自宅で続けてください（期限は10月12日（月）23:59）。 github.com/codespaces を開くと、作りかけの Codespace の続きから開けます。

commit のときに、名前やメールアドレスを聞かれる

ターミナルで次の 2 行を打ってから、もう一度 commit してください。symelon54 の 部分は、自分の GitHub のユーザー名と講義用の Gmail に変えます。本名は使いません。

git config --global user.name "symelon54"
git config --global user.email "symelon54@gmail.com"

左側の「ソース管理」に「変更の同期」というボタンがある

このボタンは、git pull（GitHub から取ってくる）と git push（GitHub に送る）を 続けて行うものです。押しても問題はなく、「"origin/main" との間でコミットをプルおよびプッシュします」と 確認が出たら OK を押せば push されます。ただ、この講義では git の動きを覚えるために、 ターミナルで git push と打つやり方を使います。

push したのに、Actions の印が出ない

1分ほど待ってから、ブラウザでページを再読み込みしてください。

2要素認証のアプリを持っていない

スマートフォンがなくても、PC 用の認証アプリ（1Password や Authy など）で設定できます。 今日は必須ではないので、わからなければ後回しにしてください。

ここに無いことで困ったとき

このページの最初の「まず、この順で解決を試す」に戻ってください。近くの席のグループに 聞いてみるのもよい方法です。
