困ったときは

Google アカウントの作成で、電話番号の確認を求められる

スマートフォンがあれば、その場で確認できます。スマートフォンがない人、確認が通らない人は、 その場で粘らずに教員を呼んでください。

GitHub のユーザー名が、すでに他の人に使われている

段階1の果物の部分を別の果物に変えて、もう一度試してください。

Claude の電話番号の確認が通らない

その場で粘らずに、Claude の登録はとばして ChatGPT と Gemini で先に進んでください。 あとで教員に伝えてください。18 歳未満の人も、Claude はとばします。

Opera で拡張機能が入れられない（「Chrome に追加」が押せない）

Opera のアドオンサイト（addons.opera.com）で「Install Chrome Extensions」を検索して入れてから、 Chrome ウェブストアのページを開き直してください。ボタンが Opera に追加 に変わります。

まもるくんを入れたのに、架空の個人情報がそのまま送信された

使っているのが Claude なら、まもるくんは働きません（対応していません）。ChatGPT か Gemini で 試してください。それでも何も起きない場合は、拡張機能が有効になっているか（ブラウザの拡張機能の 一覧でオンになっているか）を確かめてください。見落としもありうる道具なので、何も起きなかったことも 1 つの結果として覚えておいてください。

画像生成AIで「上限に達しました」と出る

無料で作れる枚数には 1 日の上限があります。もう一方のサービス（ChatGPT と Gemini）に切り替えるか、 CHARAT（charat.me）で作ってください。

Gravatar の確認メールが届かない

講義用の Gmail を開いているか（私用のアドレスを見ていないか）、迷惑メールのフォルダに入って いないかを確かめてください。数分待っても届かなければ、Gravatar は後回しにして、GitHub への アバターの登録を先に済ませてください。

「Use this template」のあと、Owner が自分のアカウントになっていない

Owner の欄が symelon-dev（教員のアカウント）のままになっていないか 確かめてください。自分のユーザー名に変えてから作成してください。

Codespaces がなかなか開かない・固まる

教室の回線が混み合っている可能性があります。1〜2分待ってから、タブを再読み込みしてください。 それでも開かない場合は、教員に伝えてください。段階5・6は、自宅に帰ってから続けることもできます （期限は10月12日（月）23:59）。

commit や push のときに、名前やメールアドレスを聞かれる

ターミナルに表示される指示に従って設定してください。わからない場合は教員または近くの人に 聞いてください。

push したのに、Actions の印が出ない

1分ほど待ってから、ブラウザでページを再読み込みしてください。

2要素認証のアプリを持っていない

スマートフォンがなくても、PC 用の認証アプリ（1Password や Authy など）で設定できます。 今日は必須ではないので、わからなければ後回しにしてください。

その他、分からないこと

近くの席のグループに聞いてみてください。それでも分からなければ、手を挙げて教員を呼んでください。
