プログラミング実践 第1回 手順書

この手順書は、ブラウザの左半分に置いて使います。右半分で実際の作業をしてください （Vivaldi・Opera のタブのタイル表示機能を使うと、左右に並べられます）。

今日のゴール

最低ライン：教室を出るまでに、自分のリポジトリ（pp2026）に 1回 push し、GitHub の確認（Actions）の印が緑になっている状態。

届かなかった人は、この手順書を見ながら自宅で続けてください。期限は 10月12日（月）23:59 です。

進め方

  1. 4人のグループで進めます。グループは教員が指定します。
  2. 各段階（下のリンク）を、グループの4人全員が終えるまで進めてください。
  3. 全員が終わったら、代表の1人が手を挙げて報告してください。
  4. 教員が4人の画面を確かめたら、各段階のページの最後にあるボタンで次の段階に進みます。
先に終わっても、1人だけ先に進まないでください。グループの誰かが分からず困っていたら、 まずそのメンバーを手伝ってください。

段階

  1. 段階1：ブラウザを用意し、講義用の Google アカウントを作る
  2. 段階2：GitHub アカウントを作る
  3. 段階3：生成AIのアカウントを作り、拡張機能を入れる
  4. 段階4：アバターを作り、Gravatar と GitHub に登録する
  5. 段階5：自分のリポジトリを作り、Codespaces を開く
  6. 段階6：プログラムを直して提出する

全部終わって時間が余ったグループは、エクストラ（作風を変えたアバター、GitHub のプロフィール、 学習アシスタントの設定など）から、好きなものを選んで挑戦してください。

うまく進まないときは 困ったときは を見てください。

今日の作業で守ること

今日はたくさんのサービスに登録します。各段階のページにも書いてありますが、大事なことをここに まとめておきます。

  • 講義用のアカウントだけを使う。どのサービスも、段階1で作った講義用の Google アカウントで登録します。私用・大学のアカウントは使いません。
  • 本名・学籍番号・大学名を、ユーザー名や表示名に入れない。GitHub・Gravatar・Claude などの 名前の欄には、GitHub のユーザー名を使います。Gravatar と GitHub のプロフィールは誰でも見られます。
  • 生成AIは、段階3で「学習に使わせない」設定にする。そのうえで、パスワードや他人の個人情報は入力しない。 入力したものは、サービスの会社に送られます（エクストラのアバター作りで自分の顔写真を使うのはかまいません）。
  • 拡張機能「まもるくん」は、ChatGPT と Gemini でしか働かず、Claude と Perplexity では働きません。 見落としもありえます。送るかどうかを最後に決めるのは自分です。
  • アバターは CHARAT で作る。他人（友人や有名人）や、既存のキャラクターに似せない。
  • Claude は 18 歳以上でないと使えません。18 歳未満の人は Claude の登録をとばしてください。
  • 有料プランの案内が出ても申し込まない。今日の作業はすべて無料でできます。
