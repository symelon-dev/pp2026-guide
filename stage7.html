A. ChatGPT で、いろいろな作風のアバターを作る

段階4では CHARAT でアバターを作りました。ここでは ChatGPT の画像生成で、作風を変えたアバターを 作ってみます。気に入ったものができたら、GitHub や Gravatar のアイコンを差し替えてもかまいません （差し替え方は段階4と同じです）。

自分の顔写真をもとにすると、自分に似たアバターができて面白くなります。写真を使わず、文章だけで作ることもできます。

写真をアップロードする前に、段階3の「5. 入力したものを学習に使わせない設定にする」で、ChatGPT の 「すべての人のためにモデルを改善する」がオフになっていることを確かめてください。 使う写真は自分だけが写ったものにします。友人など他人が写った写真、名札・学生証・住所など 個人情報が写り込んだ写真は使いません。

下のプロンプトの【人物】の部分を書き換えて使います。

  • 写真を使うとき：写真を添付し、【人物】を「添付した写真の人物。顔の特徴と髪型を残す」にする。 正面から撮った、明るい写真がうまくいきます。
  • 文章だけで作るとき：【人物】を「青いパーカーを着た、発明好きの大学生」 「黄色い帽子をかぶった、のんびりした猫」のように、好きな設定にする。

無料で作れる枚数には 1 日の上限があるので、グループで作風を分担すると、たくさん見比べられます。 友人や有名人、既存のキャラクターに似せることはしません。

うまく作るコツ

  • 気に入らないところがあれば、「背景をもっと明るく」「目を小さく」のように、直してほしい点だけを伝える。
  • アイコンは小さく表示されるので、「顔を大きく」「背景はシンプルに」と頼むと見分けやすくなる。
  • 作品名や会社名（ジブリ、ピクサーなど）をプロンプトに入れると、断られることがある。上の例のように、 線・色・質感などの特徴で伝えると通りやすい。

作風を名前ではなく特徴で伝えるのは、他人の作品をそのまままねしないための工夫でもあります。 生成AIで作った画像でも、既存の作品やキャラクターにそっくりなものを公開すると、権利の問題になることが あります。

B. GitHub のプロフィールページを作る

自分のユーザー名と同じ名前のリポジトリを作り、そこに README（説明のファイル）を書くと、 GitHub のプロフィールページの一番上に表示されます。名刺のようなもので、学期の終わりには 最終課題へのリンクを載せることもできます。

このリポジトリはPublic（誰でも見られる）にしないとプロフィールに表示されません。 本名・学籍番号・大学名・顔写真は書かないでください。好きなこと、この講義でやってみたいことなどを書きます。
  1. github.com/new を開く。
  2. Repository name に、自分の GitHub のユーザー名と同じ文字列（例：symelon54）を入れる。 「special repository」という案内が表示されれば正しい名前です。
  3. 公開範囲は Public のままにする。
  4. Add a README file にチェックを入れ、Create repository を押す。
  5. 作られた README.md の右上の鉛筆のボタン（Edit）を押し、自己紹介を書く。
  6. 右上の Commit changes... を押し、もう一度 Commit changes を押す。
  7. github.com/<自分のユーザー名> を開き、自己紹介が表示されていれば完成です。

何を書けばよいか迷ったら、生成AIに下書きを頼み、自分の言葉に直しましょう。

GitHub のプロフィール用の README.md を、Markdown で書いてください。
次の内容を入れて、短くまとめてください。本名や大学名は入れません。
- 呼び名：symelon54
- 好きなこと：（ここに書く）
- この講義でやってみたいこと：（ここに書く）
見出しと箇条書きを使い、全体で 10 行くらいにしてください。

C. 自分専用の学習アシスタントを作る

生成AIには、毎回の会話の前提として読み込ませておく「指示」を登録できます。学習向けの指示を 入れておくと、答えをいきなり全部教えるのではなく、自分で考える手助けをしてくれるようになります。

登録する場所（画面の表記は変わることがあります）
  • ChatGPT：左下（または右上）の自分のアイコン → 設定 → パーソナライズ → カスタム指示
  • Claude：左下の自分の名前 → 設定 → プロフィールの、 個人的な設定を書く欄

次の文を貼り付け、自分に合うように書き換えてください。

私はプログラミングを学んでいる大学2年生です。Python と Java の基礎は学びました。
- プログラムの質問には、すぐに完成したコードを出さず、まずヒントや考え方を示してください。
- 私が「答えを見せて」と頼んだときだけ、完成したコードを示してください。
- 専門用語を使うときは、短い説明を添えてください。
- コードを示すときは、どう動かして確かめればよいかも書いてください。

登録したら、「Python で、リストの中で一番大きい数を見つけるには？」と聞いてみましょう。 ヒントから教えてくれれば成功です。この指示は、いつでも書き換えたり消したりできます。

D. スマートフォンで講義用の Gmail を見られるようにする

GitHub の確認（Actions）が失敗したときのお知らせや、各サービスからの大事な連絡は、講義用の Gmail に 届きます。スマートフォンの Gmail アプリに講義用のアカウントを追加しておくと、届いたことに気づけます。

  1. スマートフォンに Gmail アプリを入れる（Android にはたいてい最初から入っています。iPhone は App Store から入れる）。
  2. Gmail アプリの右上の自分のアイコンを押し、別のアカウントを追加 → Google を選ぶ。
  3. 講義用の Gmail アドレス（例：symelon54@gmail.com）とパスワードでログインする。
  4. アプリの通知がオンになっているかを確かめる。

アイコンを押すと、私用のアカウントと講義用のアカウントを切り替えられます。メールを送るときは、 どちらのアカウントから送るのかに気をつけてください。

E. Codespaces の見た目を自分好みにする

Codespaces はこれから毎回使う画面です。配色（テーマ）や文字の大きさを、見やすいように変えておきましょう。

  1. Codespaces を開き、左下の歯車のボタン（Manage）を押す。
  2. Themes → Color Theme を選ぶ。
  3. 上下の矢印キーでテーマを切り替えると、画面がその場で変わる。気に入ったものの上で Enter を押す。
  4. 文字の大きさは、同じ歯車のボタン → Settings を開き、上の検索欄に font size と入れて、Editor: Font Size の数字を変える。

歯車のボタンの Backup and Sync Settings...（設定の同期）を GitHub アカウントでオンにすると、 次に新しい Codespace を作ったときも同じ見た目になります。

F. GitHub の 2 要素認証を設定する

パスワードが漏れても、他人がログインできないようにする設定です。GitHub では、多くの利用者に設定が求められています。

  1. github.com/settings/security を開く。
  2. 「Two-factor authentication」の「Enable two-factor authentication」を押す。
  3. Authenticator app を選ぶ（スマートフォンがなくても、PC 用の認証アプリで設定できる）。
  4. 表示される手順に従って設定する。
  5. 最後に表示されるリカバリーコード（復旧用のコード）は、必ずダウンロードして保存する。 スマートフォンをなくしたときに、これがないとログインできなくなります。
