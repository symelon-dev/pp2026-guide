エクストラ：早く終わったグループへ

段階6まで終わったグループ向けのおまけです。どれから始めても、全部やらなくてもかまいません。 グループの仲間がまだ作業中なら、まずそちらを手伝ってください。

E1. 4つの生成AIに同じ質問をして、答えを比べる

段階3で登録した ChatGPT・Gemini・Claude・Perplexity に、まったく同じ質問を送ってみましょう。 同じ質問でも、答え方はかなり違います。

2100年は閏年ですか？理由も、中学生にわかるように説明してください。

答えが返ってきたら、次の点を比べてください。グループで手分けして、4 つの画面を並べて見るのが おすすめです。

比べる点見るところ
正しさ段階6の流れ図と同じ結論か（2100年は閏年でない）
説明のしかたどれが一番わかりやすいか。長すぎないか
出典どこに書いてあったかを示しているか（Perplexity は出典のリンクが付く）
速さ答えが出るまでにかかった時間

Perplexity の出典のリンクは、1 つ開いて、本当にそのページにそう書いてあるかを確かめてください。 生成AIの答えを、元の情報と照らし合わせて確かめる練習です。

余裕があれば、自分で考えた質問でも比べてみましょう（本物の個人情報は入れないこと）。

E2. ChatGPT で、いろいろな作風のアバターを作る

段階4では CHARAT でアバターを作りました。ここでは ChatGPT の画像生成で、作風を変えたアバターを 作ってみます。気に入ったものができたら、GitHub や Gravatar のアイコンを差し替えてもかまいません。

顔写真はアップロードしません。文章だけで作ります。友人や有名人、既存のキャラクターに 似せることもしません。無料で作れる枚数には 1 日の上限があるので、グループで作風を分担すると たくさん見比べられます。

下のプロンプトの【人物】の部分を、自分の好きな設定に書き換えて使います。たとえば 「青いパーカーを着た、発明好きの大学生」「黄色い帽子をかぶった、のんびりした猫」などです。

ビックリマンシール系
SNSアイコン用の正方形イラスト。【人物】。
80年代の日本のおまけシールのような絵柄。太い輪郭線、デフォルメされた大きな目、
鮮やかな原色、金色の縁取り。背景は放射状のホログラムのきらめきと星。
キャラクターを中央に大きく描く。文字とロゴは入れない。

SNSアイコン用の正方形アニメイラスト。【人物】。

自然な表情、風に揺れる髪、草花や青空を感じさせる背景。穏やかな冒険の雰囲気。
顔を中央に大きく描く。文字とロゴは入れない。

背景に花びらと小さな光を散らし、明るく上品な雰囲気にする。

柔らかいスタジオ照明、温かい色合い。親しみやすい笑顔。背景は単色。
中央に大きく描く。文字とロゴは入れない。

SNSアイコン用の正方形の3Dキャラクター。【人物】。
家族向けの3Dアニメ映画のような表現。表情豊かな大きな目、丸みのある造形、
柔らかい髪の質感、映画のような暖かい照明。肩から上を中央に大きく描く。
背景はシンプルに。文字とロゴは入れない。

うまく作るコツ

  • 気に入らないところがあれば、「背景をもっと明るく」「目を小さく」のように、直してほしい点だけを伝える。
  • アイコンは小さく表示されるので、「顔を大きく」「背景はシンプルに」と頼むと見分けやすくなる。
  • 作品名や会社名（ジブリ、ピクサーなど）をプロンプトに入れると、断られることがある。上の例のように、 線・色・質感などの特徴で伝えると通りやすい。
  • できた画像は、保存してから使う。GitHub と Gravatar での差し替え方は、段階4と同じ。

作風を名前ではなく特徴で伝えるのは、他人の作品をそのまままねしないための工夫でもあります。 生成AIで作った画像でも、既存の作品やキャラクターにそっくりなものを公開すると、権利の問題になることが あります。

E3. GitHub の 2 要素認証を設定する

パスワードが漏れても、他人がログインできないようにする設定です。GitHub では、多くの利用者に設定が求められています。

  1. github.com/settings/security を開く。
  2. 「Two-factor authentication」の「Enable two-factor authentication」を押す。
  3. Authenticator app を選ぶ（スマートフォンがなくても、PC 用の認証アプリで設定できる）。
  4. 表示される手順に従って設定する。
  5. 最後に表示されるリカバリーコード（復旧用のコード）は、必ずダウンロードして保存する。 スマートフォンをなくしたときに、これがないとログインできなくなります。
