段階3：生成AIのアカウントを作り、拡張機能を入れる

この講義で使う生成AI（ChatGPT・Gemini・Claude）に登録し、使いやすくするための拡張機能と、 個人情報をうっかり送らないための拡張機能を入れます。最後に、実際に使ってみます。

どのサービスも、段階1で作った講義用の Google アカウントで登録してください。 アカウントを選ぶ画面が出たら、アドレスをよく見て選んでください。

1. ChatGPT に登録する

  1. Vivaldi で chatgpt.com を開く。
  2. 無料でサインアップ（Sign up）を押し、Google で続ける を選ぶ。
  3. 講義用の Google アカウントを選び、画面の指示に従って進める。
  4. 有料プランの案内が出ても、申し込まずに閉じる。

2. Gemini を開く

Gemini は Google のサービスなので、新しい登録は要りません。

  1. Vivaldi で gemini.google.com を開く。
  2. 右上が講義用の Google アカウントになっていることを確かめる。なっていなければ ログイン を押して、講義用のアカウントを選ぶ。
  3. 利用規約などの画面が出たら、内容を確認して進める。

3. Claude に登録する

  1. Vivaldi で claude.ai を開く。
  2. Google で続ける（Continue with Google）を選び、講義用の Google アカウントを選ぶ。
  3. 電話番号の確認を求められるので、自分のスマートフォンの番号を入れ、SMS で届いた番号を入力する。
  4. 名前を聞かれたら、本名ではなく GitHub のユーザー名（例：symelon54）を入れる。
Claude は 18 歳以上でないと使えません。18 歳未満の人は Claude の登録をとばし、 ChatGPT と Gemini だけで進めてください。電話番号の確認がどうしても通らない人も、 Claude はとばしてかまいません。

4. 拡張機能「Chat AI Ctrl+Enter Sender」を入れる

生成AIの入力欄では、ふつう Enter キーを押すとすぐに送信されてしまい、改行して長い文章を 書くのが大変です。この拡張機能を入れると、Enter で改行、 Ctrl+Enter（Mac は Cmd+Enter）で送信になります。 ChatGPT・Gemini・Claude のどれでも使えます。

  1. Vivaldi で Chrome ウェブストアの Chat AI Ctrl+Enter Sender のページ を開く。提供元が Masachika Kamada になっていることを確かめる。
  2. Chrome に追加 を押し、確認の画面で 拡張機能を追加 を押す。
Opera の人

Opera は、Chrome ウェブストアの拡張機能をそのままでは入れられません。ウェブストアのページの 上に Opera の案内（拡張機能のインストールを許可するボタン）が出たら、それを押してから Opera に追加 を押してください。案内が出ないときは、Opera のアドオンサイト （addons.opera.com）で「Install Chrome Extensions」を検索して入れてから、もう一度ウェブストアの ページを開いてください。

5. 拡張機能「まもるくん」を入れる

生成AIに送った文章は、サービスの会社のサーバーに送られます。名前や電話番号などの個人情報を、 うっかり送ってしまわないようにするための拡張機能です。送信の前に入力欄の文章を調べ、 個人情報らしきものを見つけると、確認の画面を出したり、伏せ字に置き換えたりします。 調べる処理はすべて自分のパソコンの中で行われ、外には送られないと説明されています。

  1. Vivaldi で Chrome ウェブストアのまもるくんのページ を開く。名前が「まもるくん — AIチャット個人情報ガード」になっていることを確かめる。
  2. 4 と同じように Chrome に追加（Opera は Opera に追加）を押す。
まもるくんが調べるのは ChatGPT と Gemini（と Microsoft Copilot）だけです。 Claude では働きません。また、送信を必ず止めてくれるわけではなく、 注意をうながす道具です。見落としもありえます。最後に送るかどうかを決めるのは自分です。

6. 使ってみる

ChatGPT か Gemini を開き、まず普通に質問してみましょう。改行は Enter、送信は Ctrl+Enter（Mac は Cmd+Enter）です。

次に、まもるくんが働くかを確かめます。入力欄に、次の架空の個人情報を含む文章を 貼り付けて、送信してみてください。

次の人に送るお礼のメールを書いてください。
宛先：山田 太郎さん（電話 090-1234-5678、メール yamada.taro@example.com）

確認の画面が出たり、名前や電話番号が伏せ字に置き換わったりすれば、まもるくんが働いています。 何も起きずに送信された場合は、そのことを覚えておいてください（「見落としもありうる」ことの実例です）。

自分や友人の本物の個人情報は、絶対に入力しないでください。 試すときは、上のような架空の情報だけを使います。example.com は、例として使うために 用意されている、実在しないアドレスです。

できたことを確かめる

終わったものにチェックを入れましょう。

  • ChatGPT と Gemini（18 歳以上の人は Claude も）に、講義用のアカウントでログインできている。
  • Enter で改行でき、Ctrl+Enter（Cmd+Enter）で送信できる。
  • 架空の個人情報を送ろうとしたときに、まもるくんが何をしたか（または何もしなかったか）を説明できる。
