段階4：アバターを作り、Gravatar と GitHub に登録する

アカウントのアイコン画像（アバター）を作り、GitHub などで使えるように登録します。 アイコンがあると、グループの仲間や教員が画面上であなたを見分けやすくなります。

1. CHARAT（キャラット）でアバターを作る

CHARAT は、髪型・目・服などのパーツを選んでいくだけで、イラストのアバターが作れるサイトです。 絵を描く必要はありません。

  1. Vivaldi で charat.me を開く。
  2. 好きなメーカー（絵柄）を 1 つ選ぶ。
  3. 髪型・目・服・背景などを選んで、アバターを作る。
  4. できあがったら、画像を保存（ダウンロード）する。

CHARAT で作った画像は、SNS などのアイコンとして使ってかまいません（CHARAT の利用ガイドラインで 認められています）。ただし、画像を売ること、自分で描いたと言うことは禁止されています。

友人や有名人など、他人に似せたアバターは作らないでください。アニメ・ゲームなどの 既存のキャラクターに似せることもしません。他人の権利を侵すおそれがあります。

2. Gravatar に登録する

Gravatar は、メールアドレスとアイコン画像を結びつけて登録しておくサービスです。Gravatar に 対応したサービスでは、そのメールアドレスを使うだけで、同じアイコンが自動で表示されます。 いわば、ネット上で使う「顔写真付きの身分証」のようなものです。

  1. Vivaldi で gravatar.com を開き、 Get Started（または Sign Up）を押す。
  2. メールアドレスの欄に、講義用の Gmail アドレス（例：symelon54@gmail.com）を入れる。
  3. そのアドレスに確認のメールが届くので、メールの中のボタン（またはコード）で確認する。 WordPress.com のアカウントを作るよう求められたら、そのまま作ってよい。
  4. アバターをアップロードし、切り抜く範囲を決めて保存する。
  5. プロフィールの Display name（表示名）には、本名ではなく GitHub のユーザー名 （例：symelon54）を入れる。
Gravatar のプロフィールは、初めから誰でも見られる状態になっています。本名・学籍番号・ 大学名・住所などは書かないでください。アバターと表示名だけで十分です。 気になる人は、Account Settings で「Discourage search engines」（検索エンジンに 載せない）を有効にしてください。

3. GitHub にアバターを登録する

  1. Vivaldi で github.com/settings/profile を開く。
  2. 右側の Profile picture の画像の Edit を押し、 Upload a photo... を選ぶ。
  3. 1 で保存した画像を選び、切り抜く範囲を決めて Set new profile picture を押す。
  4. 同じページの Name の欄は、空欄のままにする（本名を入れない）。

できたことを確かめる

終わったものにチェックを入れましょう。

  • github.com/<自分のユーザー名> を開くと、自分のアバターが表示される。
  • Gravatar の自分のプロフィールに、同じアバターが表示される。
