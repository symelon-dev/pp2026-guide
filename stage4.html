段階4：プログラムを直して提出する

これが今日の最後の段階です。プログラムを実行し、わざと混ぜてある不具合を見つけて直し、 提出するところまで進めます。

1. 最初のプログラムを実行する

  1. Codespaces の下側にある Terminal（黒い画面）をクリックする。 見当たらない場合は、上のメニューの Terminal → New Terminal を押す。
  2. 次を入力して Enter を押す。 
    python checkpoints/01/hello.py
  3. Hello, pp2026! と表示されれば成功です。

2. 不具合を見つける

次に、閏年（うるう年）かどうかを判定するプログラムを確かめます。

python checkpoints/01/check_leap.py

実行すると、1900年と2100年で NG と表示されます。これは、配ったプログラムに わざと不完全な部分を残してあるためです。

閏年の正しい決まり
  • 西暦が4で割り切れる年は閏年。
  • ただし、100で割り切れる年は閏年ではない。
  • ただし、400で割り切れる年は、やはり閏年。

配ったプログラム（checkpoints/01/leap.py）は、1つめの決まりしか見ていません。

3. 直す

  1. 左側のファイル一覧から checkpoints/01/leap.py を開く。
  2. is_leap_year 関数を、上の3つの決まりをすべて満たすように直す。
  3. 保存する（Cmd+S または Ctrl+S）。
  4. ターミナルでもう一度確かめる。 
    python checkpoints/01/check_leap.py
  5. 6件すべて OK になれば直せています。
生成AIに直してもらってもかまいません。ただし、自分で動かして確かめ、 なぜ直ったのかを自分の言葉で説明できるようにしてください。これは今日から 学期の最後まで続く、この講義全体の考え方です。

4. commit と push で提出する

ターミナルで、次の4つを順番に入力します。

git add -A
git commit -m "閏年の判定を直す"
git push

初めて commit するとき、名前やメールアドレスの設定を求められることがあります。表示される 指示に従ってください。

5. 確認（Actions）を見る

  1. Vivaldi で自分のリポジトリ（github.com/<自分のユーザー名>/pp2026）を開く。
  2. 上のタブから Actions を選ぶ。
  3. 一番上の実行結果の印が、オレンジ（実行中）→ 緑（成功）に変わるのを確認する。

赤い印のままだったら、check_leap.py をもう一度ターミナルで実行して確かめてください。

6. 振り返りを書く

  1. 左側のファイル一覧から checkpoints/01/reflection.md を開く。
  2. 各見出しの下の「（ここに書く）」を消して、自分の言葉で書く。
  3. 保存して、もう一度 commit と push をする。 
    git add -A
git commit -m "第1回の振り返りを書く"
git push

7. TACT で提出する

TACT の提出欄に、次の2つを入力してください。

  • GitHub のユーザー名
  • 自分のリポジトリの URL（https://github.com/<自分のユーザー名>/pp2026）

8. Codespaces を止める

無料枠を節約するため、使い終わったら Codespaces を止めます。 github.com/codespaces を開き、自分の Codespace の「…」メニューから Stop codespace を押してください。

これで今日の作業は完了です。お疲れさまでした。
